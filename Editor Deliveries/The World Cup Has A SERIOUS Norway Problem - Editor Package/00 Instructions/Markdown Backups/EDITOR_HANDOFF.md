# Editor Handoff

Project: `The World Cup Has A SERIOUS Norway Problem`

Goal: Build a fast 4:30-5:00 football documentary-style edit in CapCut using the ElevenLabs voiceover, dense B-roll, and a few proof/authority insert clips.

## Start Here

1. Import the voiceover:
   - `assets/voiceover/elevenlabs/voiceover_elevenlabs_full.mp3`

2. Follow the timestamp guide:
   - `CapCut Workflow/07 Edit Guides/CAPCUT_TIMESTAMP_EDIT_GUIDE.md`

3. Use the import checklist:
   - `CapCut Workflow/07 Edit Guides/CAPCUT_IMPORT_CHECKLIST.md`

4. Use the short B-roll index:
   - `assets/editor_package/broll_safe/short_clips/SHORT_CLIP_INDEX.md`

## Main Asset Folders

| Folder | What it contains |
|---|---|
| `assets/editor_package/broll_safe/short_clips` | Main muted B-roll clips for fast pacing. |
| `assets/editor_package/narrative_inserts` | Clips that can briefly interrupt the voiceover. |
| `assets/editor_package/graphics` | Original stat/group/tactical graphics. |
| `assets/raw_sources` | Source references and source log. |
| `assets/rough_preview` | Rough preview renders for timing reference. |

## Key Notes

- Do not use FIFA-linked clips from the first version.
- Use the ESPN insert only for `8-12 seconds` unless it feels excellent in the edit.
- Use San Siro clips as short proof moments, not long highlight sections.
- B-roll should change often, usually every sentence.
- If a clip feels risky, replace it with graphics and narration.
