## Edit Rules

- Keep the ElevenLabs voiceover as the spine of the edit.
- Most B-roll clips should run `2-7 seconds`.
- Narrative inserts should briefly interrupt the voiceover, not sit quietly under it.
- For narrative inserts, pause or heavily dip the voiceover, let the clip audio breathe, then return to narration.
- Avoid all FIFA-linked clips from Video 001.
- Use graphics when a visual topic is risky or missing.

## Timing Compression Note

The actual voiceover is about `04:37`. The timestamp table above is the base voiceover cut. If the editor allows the ESPN or San Siro insert audio to play in full, the final runtime can extend slightly beyond `04:37`, which is fine as long as the pacing stays tight.

If the edit starts drifting too long, compress these sections first:

- Supporting cast: use 1-2 second flashes per player.
- Group I section: Iraq, Senegal, France can each be 3-5 seconds.
- Final callback montage: 1-second flashes only.

Do not compress these too much:

1. Opening hook.
2. ESPN early insert.
3. San Siro proof sequence.
4. Odegaard/Haaland tactical problem.
5. Final line.

## Insert Audio Guidance

For the ESPN insert:

- Use `8-12 seconds`.
- Keep original audio audible.
- Lower voiceover to near silence during the insert.
- Add a small on-screen source label: `ESPN UK`.

For the San Siro inserts:

- Keep them short and punchy.
- If original match audio is noisy or risky, mute them and use music/SFX instead.
- Use captions or text for clarity: `1-1`, `1-2`, `1-3`, `1-4`.

## Music And Sound

- Use low, tense music under the whole video.
- Dip music slightly under narrative inserts.
- Add subtle whoosh/hit sounds only on title cards, stats, and major score beats.
- Do not let sound effects fight the narration.
