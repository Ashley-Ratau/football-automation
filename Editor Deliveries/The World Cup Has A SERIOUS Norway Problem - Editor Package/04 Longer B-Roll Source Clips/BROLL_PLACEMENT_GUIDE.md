# B-Roll Placement Guide

Use these as muted background visuals under the ElevenLabs voiceover. The goal is a fast modern football documentary pace: most clips should last 2-8 seconds, with only a few longer clips when the narration needs room.

## Pacing rule

- Change visuals almost every sentence.
- Keep player-specific visuals tied to the exact player being named.
- Use 6-10 second clips for calmer explanation sections.
- Use 1-3 second clips for list sections, stat punches, and the final warning.
- Keep B-roll muted unless there is a specific reason to feature the original audio.
