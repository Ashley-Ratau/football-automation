# CapCut Editor Handoff

Project: Gary Neville Tried To Warn Us About Cristiano Ronaldo  
Target runtime: 10-12 minutes  
Voiceover file: `assets/editor_package/voiceover/voiceover_elevenlabs_v3_full_11m27s.mp3`

## Import Order

1. Import the voiceover first.
2. Import all files from `assets/editor_package/narrative_inserts`.
3. Import all files from `assets/editor_package/broll_safe/short_clips`.
4. Import all files from `assets/editor_package/graphics`.
5. Build the timeline around the voiceover, then add inserts and B-roll.

## Main Editing Rule

This should feel like a high-retention football essay. The voiceover carries the story, B-roll keeps the screen moving, and narrative inserts act like proof points.

Do not use FIFA clips.

## Narrative Inserts

Use `assets/editor_package/narrative_inserts/PLACEMENT_GUIDE.md`.

These are the moments where the video cuts away from the voiceover and lets a pundit/player/media clip speak. Keep most of them short.

Priority inserts:

1. Gary Neville warning
2. Danny Mills Portugal-specific warning
3. ESPN bench acceptance
4. Keane/Neville debate
5. Ronaldo blanks Neville

## B-Roll

Use `assets/editor_package/broll_safe/short_clips/SHORT_CLIP_INDEX.md`.

The B-roll is already muted and cut into short pieces. Use it aggressively. The target style is frequent visual change, usually every sentence or two.

## Graphics

Use graphics only as emphasis moments:

- `graphic_warning_timeline.png`
- `graphic_portugal_talent_map.png`
- `graphic_weapon_vs_system.png`

Suggested treatment: show each graphic for 5-8 seconds with a slow zoom or slight push-in.

## Export Folder

Export the final CapCut video to:

`final video/capcut export`

Export the final thumbnail to:

`final video/thumbnail`

## Final Checks

- Voiceover should stay clear and dominant.
- Insert audio should be audible only during insert moments.
- Avoid long static sections.
- Keep B-roll clips short.
- Do not include watermarked, FIFA, or obviously blocked broadcast footage.
